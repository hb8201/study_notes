# Git 版本控制

## 版本控制工具
- CVS 集中式
- SVN 集中式
- Git 分布式

## Git控制命令

仓库：一个文件夹，被初始化后，有 git 托管

- 'git init' 初始化仓库，会创建隐藏目录 .git
- 'git status' 查看状态：干净、未追踪、待提交、待同步
- 'git add' 把未追踪的文件加入缓冲区，等待提交
- 'git commit' 提交，已经记录文件的改变，生成了存档及日志
- 'git log' 查看日志
- 'git tag' 添加标签
- 'git push' 把本地记录同步到远程
- 'git pull' 把远程同步到本地
- 'git fetch' 把远程同步到本地
- 'git breach' 分支
- 'git merge' 合并分支
- 'git checkout' 检出，回到过去的某个版本
