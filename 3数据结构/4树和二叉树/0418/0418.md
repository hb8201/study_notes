# AVL（平衡二叉树插入过程）

## 不平衡的四种情况
- LL 左左
- LR 左右
- RR 右右
- RL 右左

## 解决方法
- LL -> 右旋
- LR -> 左旋（LL）-> 右旋
- RR -> 左旋
- RL -> 右旋（RR）-> 左旋

# 红黑树

## 定义
- 节点着色，红或黑
- 总根节点为黑色
- 外部节点（叶子节点的孩子）黑色
- 不能红红，红色节点的孩子必须是黑色
- 任意节点到叶子节点的所有路径中黑色节点数量相同

## 不平衡的解决方案
- 改变着色
- 旋转（同AVL）

## 与 AVL 区别
- AVL 高度差最大为1         红黑树 路径最大值 < 2*路径最小值            AVL更平衡
- AVL 搜索更快，但插入与删除效率低与红黑树
- 红黑树插入与删除更快
- 标准库中 二分搜索树（BST）使用红黑树实现
