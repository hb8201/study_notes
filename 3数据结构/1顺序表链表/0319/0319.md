# 数据结构与算法

## 数据结构

数据：计算机可以输入、存储、处理的符号的集合，
描述客观世界的符号的集合

数据元素：数据操作的基本单位，包含多个数据项
数据项：数据的最小单位，不可拆分
数据对象：相关的数据元素的集合

数据结构 ：相互之间存在一种或多种特定关系的数据元素的集合
- 逻辑结构
    - 线性结构 1:1
        - 顺序表
        - 链表
        - 栈
        - 队列
        - 串
        - 广义表
        - ...
    - 非线性结构
        - 树 1:n
            - 二叉树
            - 完全二叉树（堆）
            
            - 二叉搜索树
            - 哈夫曼树
            - B 树
        - 图（网） n:m
- 存储结构（物理结构）
    - 顺序存储：数组
    - 链式存储：指针
    - 哈希存储
    - 索引存储
- 相关操作
    - 插入
    - 删除
    - 查找
    - 排序
    - ...

## 算法

算法：解决特定问题的方法或步骤的描述

描述
- 自然语言
- 伪代码
- 流程图
- ...

算法分析
- 时间复杂度分析
- 空间复杂度分析

分析方法
- 事后统计法
- 事前估算法

时间复杂度分析：原操作指向次数（频次）与问题规模 n 所成函数关系
- O(1)          常数阶：没有循环、没有递归
- O(logN)       对数阶：一层循环，但是循环变量 *2 +n，折半查找，二分搜索
- O(n)          线性阶：一层循环或递归
- O(N*logN)     线性对数阶：两层循环
- O(n^2)        平方阶：两层循环
- O(2^n)        指数阶：递归，斐波那契数列
空间复杂度分析：临时空间的占用和消耗
