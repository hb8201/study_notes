## 单链表

定义：节点


实现方法
- 头插法：存储序列与逻辑序列相反；翻转链表、栈
- 尾插法：

```c

    // 静态
    #define MAX 32
    
    struct List
    {
        char data[MAX];
        int len;
    };

    // 动态
    struct List
    {
        char *data;     // 8byte
        int len;
    };

    init(List *list)
    {
        // 动态内存管理（堆内存）
        list->data = malloc(32);
    }
```

```c

// 定义节点（数据元素）
typedef struct node
{
    char data;          // 数据域
    struct node *next;  // 指针域：后继
} Node;

// 定义链表：头节点（哨兵节点）、尾指针
typedef struct
{
    Node *head;     // 头节点，创建
    Node *tail;     // 尾指针，空表指向头节点，非空表指向终端节点
} List;

```
