# io - FILE 操作

## 文件概念

UNIX/LINUX '一切皆是文件'

### 狭义
- 文件
- 文件夹（目录）

### 广义 ls -l
- 文件          -： 文本文件、二进制文件
- 目录          d
- 链接          l
- 块设备        block
- 字符设备      char
- 管道          p
- 套接字        s

### 流 stream
数据（字节）的序列

- 输入流 in  读取、接受
- 输出流 out 发送、写

## C API

FILE 

- 'fopen'   打开文件，获得文件指针
- 'fclose'  关闭文件，释放文件指针
- 'fgetc'   char 读文本文件
- 'fputc'   char 写文本文件
- 'fgets'   string 读文本文件       每次读一行或者一个缓存区大小
- 'fputs'   string 写文本文件
- 'fread'   读二进制文件，文本文件    每次读一个缓冲区大小
- 'fwrite'  写二进制文件，文本文件
- 'fseek'   任意访问
- 'ftell'   获得当前位置距离文件开头的字节数
- 'rewind'  回到文件开头位置
- 'fprintf' 格式化输出到文件
- '...'
