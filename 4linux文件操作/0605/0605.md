# openssl                   -lcrypto

## MD5、SHA1、SHA256
- 数字指纹、摘要、唯一性
- 加密
- 不可逆
- 密码 SHA256 加密 + 盐

## Base64 编码与解码
- 二进制转为文本格式
- 文件会增大 4/3
- 双向
- 简单加密
- 64钟字符 a~z 26*2 0~9 + /(=)

## 加密与解密
- RSA 非对称密钥加密与解密

2. base64 的使用场景
- 把 二进制数据 → 可打印的文本字符串
- 网络协议传输：只支持文本的通道
- Cookie / URL / Header 传输    这些位置不能存特殊字符、二进制、中文，会被截断、乱码。
- Token 与加密数据传输（JWT）   JWT（登录令牌）= 头部 + 载荷 + 签名，全部用 Base64 编码。
- 配置文件 / 数据库存储二进制   很多配置文件、数据库字段只支持字符串，不能直接存图片、文件字节。
- 代码 / 文本里嵌入二进制资源   把文件写死在代码里，不依赖外部文件。
