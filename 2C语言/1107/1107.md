### apt - 高级包管理工具

- apt update        更新软件清单，不安装
- apt upgrade       执行更新，安装
- apt install sl
- apt remove sl
- apt show sl
- apt search sl

### shell
一个软件程序，集成了各种命令程序，为用户提供一套一致的用户交互的方式

- bash  `*`
- zsh   `*`
- csh
- fish  `*`

### 安装包
1. 授予执行权限
    chmod u+x xxx.deb
2. 安装
    sudo apt install ./xxx.deb
