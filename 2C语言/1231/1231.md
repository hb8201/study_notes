# 指针

## 概念

指针是一种数据类型，存储其他变量的空间地址，空间的起始地址（第一个字节的地址）

### 数据类型
- 基本类型（原始类型）
- 组合类型（复合类型）：数组、结构体、联合体、枚举、类
- 指针
- void

## 定义

类型 *变量名

```c
    // 普通变量
    int     a;   // 4
    char    c;   // 1
    double  g;   // 8
    int     m[100]; // 100*4 = 400

    // 指针变量，空间大小与平台有关 32位系统4字节，64位8字节
    int     *p1;    // 8
    char    *p2;    // 8
    double  *p3;    // 8

    p1 = &a;    // a的地址存入变量p1, 指针p1指向a
    int x;
    p1 = &x;    // p1 指向 x

    // 解引用、间接运算
    int r = *p1;
    *p1 = 99;
```

### * 运算符
- 若在数据类型的后面，* 声明指针类型的变量
- 变量名前没有数据类型，* 解引用（间接运算）操作指针指向的空间（读或写）

## 应用
- 函数参数传递
- 减小内存浪费
- 数组操作（指针运算 +,-）
