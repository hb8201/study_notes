# 指针、数组

## 指针
指针是一种数据类型，存储其他变量的地址
指针大小由平台决定，64Linux 8字节


```c
    // *, &
    int a = 1;
    // * 1) 声明指针类型的变量 2) 解引用，访问指针指向的空间
    int *p = NULL;

    // & 取地址符
    p = &a;

    // 间接，
    *p = 3;
    int x = *p;

    // 声明，未赋值的指针叫野指针
    char *p2;
    // *p2 = 'A';   不能对野指针进行解引用
```

### 野指针
- 声明后，未初始化或未赋值的
- 动态内存分配（malloc）空间，释放(free)后，野指针

避免野指
- 声明时进行初始化有效值
- 声明时赋值 NULL (0)
- 

### 空指针
- 初始化时，赋值 NULL
- 动态内存管理，free 之后，赋值 NULL

### 空指针是确定值，野指针是不确定值

## 指针与数组

数组名

- 数组的地址
- 数组第一个元素的地址

### 指针的运算（地址的偏移，单位为数据类型）
- 指针加法
- 指针减法
- 两个指针相减

```c
    int a[4] = {0};
    int *p = a;

    a++;    // 错误
    p++;    // 有效
```

## 常量指针与指针常量

## 指针与函数

函数返回指针
- 指针变量是 static 类型
- 指针的数据动态分配 malloc

```c

    int *f()
    {
        static int *p;
        return p;
    }

    int *f()
    {
        int *p = malloc(sizeof(int));   // 手动分配
        return *p;
        // free(p)
    }

    在函数外可以继续访问空间，
```
