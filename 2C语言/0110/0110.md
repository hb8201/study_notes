# 字符串

## 定义

```c
    char s1[16] = "abc";  // sizeof=16 strlen=3
    // s1 = "xyz";
    s1[0] = 'x';

    char *s2 = "abc";     // sizeof=8 strlen=3
    s2 = "xyz";
```
## 函数

在标准库 string.h 中定义字符串相关的函数
- `strlen`  长度
- `strcpy`  复制
- `strcat`  拼接
- `strcmp`  比较
- `strchr`  查找字符
- `strstr`  查找字串
- `strtok`  差分字符串
- `strnxxx` n范围安全的, 多一个参数
- `memcpy`  内存拷贝
- `memmove` 内存移动
- `memset`  内存填充
- `memcmp`
