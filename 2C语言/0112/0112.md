# 动态内存管理

堆空间的内存

- malloc
- free
- calloc
- realloc

## void *

通用指针
- 存储其他类型的指针的值
- 不能解引用
- 强制转换为具体指针再解引用


void * 不是空指针，

空指针：NULL 宏定义，0
野指针：没有初始化，被free后的，不确定行为

```c
    char c;
    int i;

    // 具体指针
    char *p1 = &c;
    int *p2 = &i;

    void *p;

    p = p1;     // char *
    p = p2;     // int *

    // *p = 123;       // 错误
    int *p3 = (int *)p;
    *p3 = 42;

```


## 流程

1. 使用 malloc 分配内存

2. 若空间不足 realloc 重新分配，指针的值可能会改变

    ptr = realloc(ptr, size);

3. 必须使用 free 释放堆内存，可以赋 NULL

    free(ptr);
    ptr = NULL;

4. calloc() 等价于 malloc() 加 memset(ptr, 0, n)
