## 数组
一块连续的存储空间，可以存储类型相同的多个元素，容器
数组中元素有序存储，通过索引 index（下标）【随机】访问数组中的元素
下标从 0 ~ n-1

避免：数组下标越界


```c
    // 整型数组 a 容量是 5， 4byte * 5
    int a[5];

    int n;
    n = 6;
    long b[n];  // 6

    // 二维数组
    int m[3][4];
    int m[3][4][5];

    // 数组初始化
    int a[3] = {1, 2, 3};   // 完全初始化
    int a[3] = {1};         // 部分初始化，未初始化为 0
    int a[]  = {1, 2, 3};   // 容量为实际大小

    //
    int a[3];
    // a = {1, 2, 3};
    a[0] = 1;
    a[1] = 2;
    a[2] = 3;

```
