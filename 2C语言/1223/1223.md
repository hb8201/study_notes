## 定义与调用

```c
bool is_prime(int n)
{
    // 标识符
    bool flag = true;
    // 2~n的平方根
    for (int i = 2; i*i <= n; i++)
    {
       if (n%i == 0)
       {
            flag = false;
            break;
       }
    }
    return flag;
}
```
