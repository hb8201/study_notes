# 运算 & 流程控制

## 流程控制

### 分支 - switch

```c
    // 多路分支
    // int, char, 枚举
    switch (var)
    {
        case 1:
            // 1
            break;
        case 2:
            // 2
            // break;
        case 'A':
            // 3
            break;
        case 'Z':
        case 'z':
            // 4;
            break;
        default:
            // 5
            break;
    }
    // next

```

### 循环结构

- `while`       次数不确定，由条件决定
- `do-while`    
- `for`         使用循环计数器，循环次数确定

```c
    // 先判断，再执行；循环体执行 0~n
    while ()
    {
        // 循环体
    }

    // 先执行，再判断；循环体执行 1~n
    do
    {
        // 循环体
    } while ();

    // 1. 循环变量初始化：1
    // 2. 循环条件：1~n
    // 3. 循环变量的改变【步长】
    // 4. 循环体: 0~n
    // 1,2,4,3,2,4,3....2
    for (1; 2; 3)
    {
        // 4
    }

```
