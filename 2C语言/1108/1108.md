### 安装包

1. 授予执行权限
    chmod +x xxx.deb

2. 安装
    sudo apt install ./xxx.deb

## 打包

- .zip
- .tar.gz   `*`
- .rar

### tar
打包
    tar -cvf abc.tar a.txt b.txt c.txt

压缩,额外加 z
    tar -czvf abc.tar a.txt b.txt c.txt

解压
    tar -xzf abc.tar.gz

### zip
压缩
    zip -r abc.zip dir abc.txt

解压
    unzip -x abc.zip

### rar
压缩
    rar -a abc.rar dir a.txt

解压
    unrar x abc.rar

## 从源代码构建

1. 下载源代码
    wget https://github.com/xxxxxx.tag.gz

2. 解压缩
    tar -xzvf xxxx.tag.gz

3. 构建(make)
    cd redis-8.4
    make

4. 运行程序
    cd src
    ./redis-server


## 服务管理

- service
- systemctl

### service

ssh - openBSD secure shell
- 服务器: openssh-server / sshd
- 客户端: ssh

- service ssh status    显示状态
- service ssh start     启动服务
- service ssh stop      关闭服务
- service ssh restart   重启服务
