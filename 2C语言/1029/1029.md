## UNIX/Linux 目录结构

相对路径：没有起始位置，cd abc, cd ../abc, cd ~/abc
绝对路径：cd /var, cd /etc/mysql

目录结构
- `/`       根目录                                                             
- `/bin`    binary 程序                                               存放所有用户都能使用的基本命令（如 ls、cp）
- `/sbin`   系统管理程序                                               存放系统管理员专用管理命令的目录，通常只有root用户才能执行其中的命令
- `/boot`   启动、引导程序 bootloader                                   包含启动 Linux 所需的核心文件
- `/root`   根用户，管理员的用户目录
- `/home`   用户目录，/home/bob, /home/tom, /home/alice
- `/dev`    设备（硬件）投影     device                                  设备文件目录，硬件设备（如硬盘 /dev/sda、键盘）
- `/proc`   进程投影            process
- `/sys`    系统投影            system
- `/etc`    配置信息（注册表）                                           统配置文件中心，存放所有系统和应用程序的配置文件
- `/mnt`    mount 挂载设备                                             用于临时挂载外部文件系统，如USB设备、DVD或网络文件系统,手动挂载
- `/cdrom`  挂载                                                       专门用于挂载光盘驱动器等光存储设备
- `/media`  挂载                                                      自动挂载可移动介质，如U盘、SD卡、CD/DVD等
- `/var`    可变，日志、部署     variable
- `/tmp`    临时目录            temporary
- `/usr`    unix system resouce                                         用户可读取的应用程序和文件（头文件）
- `/opt`    可选，手动安装软件资源                                         第三方软件安装目录
- `/lib`    库目录：OpenCV、mySQL                                         系统运行所需的共享库文件
- `/lib64`

sudo 以管理员身份执行特定指令
sudo su 直接切换到 root 身份
exit    退出当前身份
