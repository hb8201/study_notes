# 位运算 & 字符

## 位运算

数值转化为二进制逐位进行运算，结果数值

- `&`   与
- `|`   或
- `^`   异或
- `~`   取反
- `>>`  右移
- `<<`  左移

### & 与

两个1得1，其他得0，掩码运算

```c
    int a = 2;
    int b = 3;
    // 1010101000   x
    // 0000000100   4
    // 0000000000

    if (a % 2 == 1) // % 除法取余数
    if (a & 1 == 1) // 
    // 1010101x
    // 00000001
    // 0000000x
```

## ^ 异或

一样得0，不一样得1

    1100
    1010
    ----
    0110

```c
    int a[] = {12, 13, 42, 13, 15, 12, 15};
    
    int n = 0;
    for (int i = 0; i < 7; i++)
    {
        n = n ^ a[i];
    }
    printf("%d\n", n);
    return 0;
```

## ~

一元运算，按位取反

```c
    // 00000000001
    // 10000000001  -1
    // 负数：按位取反，再加一
    int a = 3;      //  0000 0011
    int b = ~a;     //  1111 1100 = -4

    printf("%d\n", b);

    printf("%032b\n", a);
    printf("%b\n", b);

    printf("%d,%d\n", 13, ~13);
    printf("%d,%d\n", -13, ~(-13));
    printf("%d,%d\n", 0, ~0);
```

## >> 位移

<<  左移动，在原数值右侧补 0，乘以 2 的 n 次方
>>  右移动，低位截断，左则补 0，除以 2 的 n 次方

4 << 3
    0100000

15 >> 3         15 / 8 = 1
    0001

```c
    int n;
    printf("请输入整数：");
    scanf("%d", &n);

    // 方向反了
    // while (n > 0)

    //     printf("%d", n % 2);
    //     n /= 2;

        // printf("%d", (n >> (31 - i)) & 1);

        int b = 1 << (31 - i);
        printf("%d", (n & b) == b); // 1,0

    }
```
