# 嵌入式

## 嵌入式系统

系统就是为了实现一个共同目标，而把多个不同的部分有机组合起来的一个整体

嵌入式系统就是为特定应用场景而设计的专用计算机系统。

流程

- 开发环境搭建

### 硬件
- 常规电路
- 接口
    - GPIO  通用输入/输出，本质上就是芯片伸出来的一根根数字引脚，高低电平（0、1信号）
    - UART  通用异步串行通信协议，数据是一位一位（bit）按顺序传输的，需要提前约定好波特率 1v1
    - I2C   集成电路总线，同步通信
    - SPI   串行外设接口，全双工、同步的串行通信
    - CAN   控制器局域网总线

### ARM 架构
- RISC（ARM）：精简指令集指令系统
    - 指令系统简单（100条指令左右） 寻址方式相对少（18种左右）
    - 所以指令格式整齐，每条指令执行时间基本一致，可以组织流水线
    - 存储器与cpu之间的数据交互     加载-存储”架构：LOAD（读内存）和 STORE（写内存）指令能碰内存，其他计算指令（如 ADD）只能操作寄存器。

- CISC（x86）：复杂指令集指令系统
    - 所以功能都有专用的指令完成  系统指令烦杂，指令寻址方式多
    - 存储器”架构：绝大多数运算指令（如 ADD）可以直接对内存里的数据进行操作，无需先搬进寄存器。

### 体系架构

架构
- 中央处理器（CPU）——大脑（控制器 + 数据通路/ALU）。
- 内存（存储器）——存储指令和数据。
- 输入/输出（I/O）——与外界交互。
- 系统总线（互连）——连接上述所有部分的通路。


- 冯·诺依曼架构：程序存储与数据存储是统一的
- 哈佛架构：程序存储与数据存储是独立的

### 处理器模式
- 用户模式          正常程序执行模式，不能直接切换到其他模式
- 系统模式          运行操作系统的特权任务，与用户模式类似，但具有可以直接切换到其他模式等特权
- 一般中断模式      用于通用中断处理，IRQ异常响应时进入此模式
- 快速中断模式      支持高速数据传输及通道处理，FIQ异常响应时进入此模式
- 管理模式          操作系统保护模式，系统复位和软件中断响应时进入此模式
- 中止模式          用于支持虚拟内存和/或存储器保护
- 未定义指令终止    支持硬件协处理器的软件仿真，未定义指令异常响应时进入此模式
