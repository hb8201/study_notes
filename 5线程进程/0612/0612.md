# pthread 线程

## 进程与线程
进程：程序的一次执行过程，及在这个过程中获得CPU、内存、文件、网络等资源
- 一个程序运行默认一个进程，但可以创建多个子进程
- 每个进程的资源都是相互隔离的

线程：是进程中的执行单元，一个进程中默认存在一个主线程
- 可以创建多个子线程，多个线程可以共享进程中的资源

## POSIX

POSIX 可移植 OS 接口扩展，一套由 IEEE 定义的技术规范
很多操作系统遵循 POSIX 规范：UNIX（IBM,Oracle,HP）、Linux、MacOS、鸿蒙


## Pthread

- POSIX thread
- C++ 11 / boolst thread
- OpenMP
- CUDA
- 微软

相关 API
- pthread_t                 线程ID
- pthread_create()          创建一个新的线程
- pthread_join()            主线程等待 join 的线程执行
- pthread_self()            获得线程ID
- pthread_exit()            结束线程
- pthread_cancel()          撤销线程
