# pthread 线程

## 线程的生命周期
- 新建  pthread_create()
- 就绪  OS 调度，获得 CPU 时间片
- 运行   -> 1.结束 2.就绪 3.阻塞
- 阻塞  sleep()/wait 让出来 CPU 时间片 -> 就绪
- 结束

## 分离态与非分离态
- join      非分离态（默认），pthread_join()，若不 join 出现僵死线程
- detach    分离态，子线程与主线程分离，不可 join，不返回数据，任务结束自动释放资源

### 非分离态

```c
int main()
{
    // 创建子线程
    pthread_create(t1,...);
    // 其他语句
    code 1                  // 与pthread_create() 同时执行
    pthread_join(t1,...);   // 等待子线程 t1 结束，并获得返回值
    code 2                  // 等待pthread_join() 运行完执行
    code 3
    // 结束当前（主）线程，进程还在，子线程 t1 可以继续执行，进程未结束前 t1 成为僵死线程
    pthread_exit(NULL);
    return 0;               // 结束进程，所以资源销毁
}

```
