## 事务处理

事务：一个业务操作包含多个数据操作（DML），这多个数据操作在操作逻辑上是一个整体，它的执行或者撤销被称为一个事务，包含四个特性：原子性，一致性，隔离性，持久性

ACID
- 原子性：构成事务的多个数据操作是一个整体，不可分割，执行时要么成功，要么撤销
- 一致性：事务执行前后，数据总值不变
- 隔离性：多个事务执行期间，相互隔离，隔离级别：读未提交、读已提交、可重复读、串行化
- 持久性：事务结束，数据写入磁盘

TCL
- `BEGIN`       开启手动事务模式，直到提交
- `COMMIT`      提交
- `ROLLBACK`    回滚

### 隔离级别

|隔离级别|读未提交|读已提交|可重复读|串行化|
|--|--|--|--|--|
|`脏读`| + | - | - | - |
|`不可重复读`| + | + | - | - |
|`幻读`| + | + | + | - |

脏读： 读取到其他事物未提交的数据
不可重复读：事务中，多次读取的数据不一致
幻读：事务中，因插入和删除引发的数据不一致

```sql
--转账
BEGIN;
update account set balance=balance-5 where id=1;
update account set balance=balance+5 where id=2;
insert into log(`from`,`to`,amount) values(1,2,5);
commit;
-----------------
begin;
update account set balance=balance-5 where id=3;
update account set balance=balance+5 where id=4;
insert into log(`from`,`to`,amount) values(3,4,5);
rollback;
```
