# 数据库 - 视图、函数存储过程、C API

## 回顾

- 关系范式：1NF 2NF 3NF
    - 1NF：列的数据是原子性的
    - 2NF：有复合主键情况下，非键字段要依赖所有主键
    - 3NF：非键字段之间不能存在直接依赖关系
- 表之间的关系
    - 1对1：共享主键 last_insert_id()，序列 currval(),nextval()
    - 1对多
    - 多对多：通过中间表建立
- 表连接
    - 内连接
    - 左外连接
    - 右外连接
    - 全连接
- 事务：业务的多个数据操作，它的执行或者撤销被称为事务
    - A 原子性：多个数据操作在逻辑上是一个整体，要么全部执行，要么全部回滚
    - C 一致性：事务前与事务后总数据不变
    - I 隔离性：多个事务之间相互隔离
        - 隔离级别
            - 读未提交 +++
            - 读已提交 ++-
            - 可重复读 +--
            - 串行化   ---
        - 状况
            - 脏读：读取到其他事物未提交的数据
            - 不可重复读：事务中，多次读取的数据不一致
            - 幻读：事务中，因插入和删除引发的数据不一致
    - D 持久性：事务结束，数据写入磁盘

- 索引：通过 B+Tree/Hash 实现提高查询数据效率的方法，但占用磁盘空间
    - 类型
        - 主键索引
        - 唯一索引
        - 普通索引
        - 全文索引
        - 空间索引
        - 位图索引：用于低基数列
    - 技术实现
        - B+Tree
        - Hash
        - RTree
    - 主键、外键、唯一约束：自动创建索引
    - 手动创建索引：在使用 where、group by、group by 时创建

视图里的数据能否更改？
- 数据来自于一张表且没有使用函数，都是原始数据，则可以插入、更新、删除
- 数据来自于不同表或者使用函数，不可进行插入、更新、删除

表：数据的存储结构
视图：数据的逻辑结构、业务结构

```sql
create view v_staff
as
select s.id, s.name, d.name dept, d.city, s.salary
from staff s
left join dept d
on s.dept_id=d.id
order by s.salary desc;

-- 查看各个部门人数
create view v_dept
as
select d.id, d.name, count(s.id) N
from dept d
left join staff s
on d.id = s.dept_id
group by d.id, d.name
order by d.id;
```

## MySQL C API

### 核心数据（结构体）
- MYSQL         数据库连接
- MYSQL_RES     执行 SQL 获得的资源，结果集
- MYSQL_ROW     从结果集获取的一行数据，记录，字符串数组
- MYSQL_FIELD   列、字段的元数据：列名、类型、大小

### 函数
- mysql_init()
- mysql_real_connect()      连接mysql服务器
- mysql_close()             关闭mysql服务器连接
- mysql_real_query()        执行sql语句
- mysql_store_result()      检索并存储整个结果集
- mysql_fetch_row()
- mysql_fetch_field()
- mysql_close_res()
