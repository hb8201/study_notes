# 数据库

## SQL 优化
- 索引：B+Tree（3~4层）、Hash
    - 自动：主键、外键、唯一约束
    - 手动：where、join、oredr by、group by
    - 避免了全表扫描、回表问题
    - 影响插入、更新、删除性能
- 优化 SQL 语句
    - 禁用 SELECT *
    - 避免子查询和临时表（基于执行计划再次优化）
    - join 小表驱动大表
    - 批量写入
        - insert into t1 values(), (), ();
        - 并入事务 begin insert...; insert...;  insert...;  commit
    - 执行计划 explain
        - `explain select ...`
- 使用缓存 (*)
    - redis
- 分表
    - 水平分区
        - 表分区：数据范围 range、list、hash
        - 水平发表：create table t1_p1 as select...;
    - 垂直拆分（列）
- 分库
    - 读写分离：主从架构，主库写，从库读
