# 数据库

## 数据库

数据库管理系统（DBMS）：`数据库服务器`，是一个软件，核心功能创建数据库，操作数据库，数据库的备份与恢复

`数据库`：磁盘上的一组文件（数据文件，日志文件，控制文件等）

`数据库实例`：数据库服务器加载数据库文件创建的进程

### SQL 结构化查询语言

一套技术规范，标准刷 SQL

#### DDL 数据定义语言（数据库）
- `CREATE`      创建
- `DROP`        删除
- `ALTER`       修改
- `TRUNCATE`    截断
- `...`

#### DML 数据操作语言（表）
- `INSERT`      增
- `DELETE`      删
- `UPDATE`      改
- `SELECT`      查
- `...`

#### TCL 事务控制语言
- `BEGIN`       开始
- `COMMIT`      提交
- `ROLLBACK`    回滚
- `...`

```sql
-- 创建
create table person
(
    name varchar(16) NOT NULL,
    age int default 18,
    gender enum('male', 'female') default'female',
    tel char(11)
);

-- 查看表结构
desc person;

-- 插入
insert person values('bob', 21, 'male', '18632938431');
insert person(name) values("alice");
insert person(name, age) values("jack", 23), ("king", 60);

-- 查询表中的数据
select * from person;

```

## 关系建模

表存储
- 实体或概念的属性，表由多个列（字段），由多行（记录）构成
- 实体与实体的关系

关系建模 - 关系代数

关系范式
- 1NF：列的数据原子性（表中列的数据是单一的）
- 2NF：非键字段要直接依赖于主键字段，与主键没有依赖关系的直接拆分，可以创建复合主键
- 3NF：非键字段之间不存在依赖关系

```sql
-- PK 主键约束
-- FK 外键：建立两张表之间的关系（是另一张表的主键值）
create table t5
(
    id          int auto_increment primary key
    name        varchar(16),
    gender      enum('男','女'),
    birthday    date,
    tel         char(11),
    mother      int
);

```
