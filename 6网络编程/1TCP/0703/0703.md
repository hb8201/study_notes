# 套接字编程 - TCP

## 套接字 socket

套接字 = IP + 端口 + 传输协议 (TCP/UDP)

套接字是 TCP/IP 实现中出现的概念，封装了网络底层通信的细节，操作方式类似于文件

### IP 地址(IP 负责找到哪一台电脑)
接入网络的计算机的逻辑标识（可变的），动态分配给计算机的标识信息

MAC地址：物理标识，硬件设备的标识，出厂设定，唯一标识

IPv4: 2^32
IPv6: 2^128

### Port 端口号(端口负责找到电脑上哪个程序)

一台计算机有唯一IP标识，同时运行多个进程，端口号标识收、发数据的进程
端口号也是虚拟的 2^16, 65536个，前1024保留

## TCP 套接字 API
- socket()      创建套接字文件描述符 return (int)
- bind()        绑定地址
- listen()      开启监听，初始化队列
- accept()      接受请求
- read/write    读写
- close()       关闭

### 大小端

- htons 主机到网络短整型
- htonl 主机到网络长整型
- ntons 主机到主机短整型
- ntonl 主机到主机长整型

0x12345678

空间：  0   1   2   3
大端： 12  34  56  78

空间：  0   1   2   3
小端： 78  56  34  12

- Little Endian     x86架构处理器是小端
- Big Endian        网络通信是大端
