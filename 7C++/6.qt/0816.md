# Qt

## Qt   一个跨平台的 C++ GUI 库（跨平台应用程序开发框架）

- Q_OBJECT 元对象系统
- MOC Meta Object Compiler 元对象编译器
    - 动态属性绑定
    - 信号与槽

功能：一整套计数解决方法
- GUI
- 文件、网络、线程、数据库、数据解析、STL
- 多媒体、蓝牙

## 开发方案
- Qt Widgets 命令式开发：C++
- Qt Quick 声明式开发：QML + JS + C++


Rectangle 矩形

anchors 锚点

spacing 间距

ColumnLayout 列布局
RowLayout 行布局
GridLayout 网格布局

Layout.preferredHeight 布局中高的权重
Layout.columnSpan 网格布局中列的跨度

TextField 文本框
placeholderText 文本占位符
Button 按钮
onClicked 事件处理
