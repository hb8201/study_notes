## 容器
数据结构的具体实现
https://learn.microsoft.com/en-us/cpp/standard-library/stl-containers

- 序列容器（顺序容器），线性表
    - vector            动态数组，自动扩容
    - array             固定数组，支持泛型<T>
    - list              双向循环链表
    - forward_list      单向链表
    - deque             双端队列（double_end_queue），头尾插入O(1)，分段存储
- 有序关联容器（红黑树 - 平衡的二叉搜索树 logN）
    - set               无重复值的集合
    - multiset          有重复值的集合
    - map               无重复值的键值对
    - multimap          有重复值的键值对
- 无序关联容器 （哈希表，搜索速度O(1)）
    - unordered_set     无序集合
    - unordered_map     无序键值对
- 容器适配器：基于已有的容器封装而成
    - stack(deque)      栈
    - queue(deque)      队列
    - priority_queue    优先级队列，基于 vector 实现

### 泛型与模板编程

泛型：类型参数化，编程过程对数据类型解耦

模板编程是 C++ 实现泛型的一种技术手段

对于相同功能的函数或者类因为参数类型不同而需要反复创建的情况，将它们的类型参数化，就可以根据传入参数的类型不同而实现对应的操作

泛型
- 模板编程 C++
- 带参数宏 C
- 类型擦除 Java
- 动态类型 Python, Js

## 算法

Lambda 表达式：匿名函数
[捕获列表](参数列表)->(返回值类型){主体}

### 算法函数
    - sort(1.起始, 2.末尾, 3.排序规则(Lambda 表达式))          排序,排序规则不写,默认从小到大
    - for_each(1.起始, 2.末尾, 3.具体操作(Lambda 表达式))      遍历一个范围内的所有元素
    - find_if(1.起始, 2.末尾, 3.过滤条件(Lambda 表达式))       过滤,返回一个迭代器
    - count(1.起始, 2.末尾, 3.值)                            统计,返回等于这个值的数量
