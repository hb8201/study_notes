# C++ 面向对象编程

## 设计模式 - 可复用面向对象软件的基础

GoF 《设计模式》23种
- 创建型模式
    - 单例模式 Singleton
    - 工厂模式 Factory
    - 建造者 Builder
    - 享元/蝇量
- 结构型模式
- 行为型模式

### 单例模式 Singleton
- 类只能创建一个对象
- 在任意位置获得的这个类的实例都是同一个对象

实现：
- 构造方法私有化（分装），屏蔽了访问方法
- 提供一个静态接口（类接口），获得唯一实例（对象）


### 工厂模式 Factory
- 静态工厂（简单工厂）
- 抽象工厂

实现：
- 定义一个创建对象的接口，但让子类决定实例化哪个具体类
