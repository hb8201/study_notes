# C++ - 面向对象编程

## 对象与类

类：对象的定义（模版），对具有相同属性、行为的一组对象的定义
对象：具体存在，类的实例

## 组合：整体与部分的关系 has-a
- 组合：强组合，部分不能脱离整体存在，整体销毁部分也销毁
- 聚合：弱组合，部分可以脱离整体存在，整体销毁部分还存在
- 关联：存在联系，不是整体与部分

```c++
// 对象 强组合
class Line
{
    Point s;
    Point e;
}
// 指针 弱组合（聚合）
class Line
{
    Point *s;
    Point *e;
}
// 引用 关联
class Line
{
    Point &s;
    Point &e;
}
```

## 继承

角色
- 父类、基类、超类
- 子类、派生类：获得了父类中的属性和行为

特性
- 代码复用：多个类公共的成员提取出来放入父类中
- 易于维护或拓展

类型
- 单继承
- 多继承：存在副作用，能避免就避免 （一个子类同时拥有两个或两个以上的直接父类）

属性
- 子类拥有父类中的所有属性：私有（不能直接访问，但可通过构造函数初始化）、受保护、共有的
- 子类中可以访问父类的 受保护、共有的

方法
- 子类可以覆盖父类中的方法：（重写） override，父类的方法是虚函数（virtual）
- 指针类型与对象类型不一致：父类的析构函数必须是虚函数，否则子类析构不执行

## 多态

方法行为的多态，根据参数类型、参数个数、对象类型选择不同版本的方法执行，呈现不同的行为

- 方法重载：一个类中存在 同名不同参 的方法导致，编译时选择对应参数的方法执行
- 方法重写：在继承关系中，子类覆盖了父类的同名方法，根据对象类型属于哪个类而选择哪个类的方法

## 纯虚函数：抽象类、接口类

抽象类：内部有纯虚函数的类，不能实例化（不能直接创建对象）
    - 只少有一个纯虚函数
接口类（特殊的抽象类）
    - 所有函数是纯虚函数（析构函数例外）
    - 没有成员属性
    - 所有东西是公共的
